Project for the Generative AI course (Università degli Studi di Brescia)
The project aimed to analyze an existing detector performances with original images and with compressed images.
The used compressor is JPEG AI.
The used synthetic detector is at [this repository]{https://github.com/polimi-ispl/synthetic-image-detection.].

We also create a Bridge architecture for using the latents generated by the compressor in order to obtain better results for the detection.
